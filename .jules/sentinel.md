## 2024-05-18 - Input Validation and Algorithmic DoS Vulnerabilities
**Vulnerability:** Missing input type validation led to unhandled Internal Server Errors (500) that could leak internal stack traces when receiving non-string inputs (like lists or objects in JSON payloads). Additionally, lack of bounds checking on the size of inputs allowed for Algorithmic Denial of Service (DoS) due to the \(O(N^2)\) worst-case time complexity of building a Binary Search Tree (BST) from sorted arrays.
**Learning:** The `validate_number_list` function blindly assumed string methods (`replace()`, `split()`) without ensuring type correctness or placing limits on payload length or resulting array size. Since `app.py` sorts the array before generating the BST, an attacker supplying a long list will trigger worst-case BST construction performance, hanging the server for tens of seconds per request.
**Prevention:** Always validate the type of dynamically-typed inputs (e.g., from JSON deserialization). Impose strict upper limits on input payload sizes and processing dimensions (e.g., maximum array lengths) to cap computational resources and block Algorithmic DoS attempts.
